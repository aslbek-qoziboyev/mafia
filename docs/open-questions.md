# Aniqlashtirilmagan o‘yin qoidalari

Quyidagi qoidalar mahsulot egasi tasdiqlamaguncha ataylab hal qilinmagan. Backend yoki interfeys ularni o‘zicha taxmin qilmasligi kerak.

1. Don Mafia jamoasining tun uchun yakuniy qarorini qanday tasdiqlaydi?
2. Jodugarning har bir iksiridan nechta foydalanish mumkin va u o‘zini nishonga olishi mumkinmi?
3. Advokat o‘zini himoya qila oladimi?
4. O‘yinchi bergan ovozini o‘zgartira oladimi?
5. O‘yinchi o‘ziga ovoz bera oladimi?
6. Manyak tirik qolgan yagona o‘yinchi bo‘lsa, jamoaviy g‘alaba qanday hisoblanadi?
7. Dastlabki moderator qanday tanlanadi?

Tasdiqlangandan keyin ushbu hujjat, qabul mezonlari va server qoidalari birgalikda yangilanishi kerak.
